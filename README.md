### ALGO-000133: n log n bits for adversarial-order Max-Cut estimation
- **Subfield:** Online algorithms and streaming
- **Open:** Prove an \(\Omega(n\log n)\)-bit lower bound for one-pass adversarial-order Max-Cut value approximation better than \(1/2\) by a fixed constant.
- **Status:** Linear lower bounds leave a logarithmic gap from natural sketching upper bounds.
- **Type:** impossibility
- **Why:** Would settle whether storing vertex-scale information necessarily incurs word-sized identifiers.
- **Key works:** Kapralov and Krachun’s Max-Cut streaming lower bounds; Singer (2025), *Nine Lower Bound Conjectures*.
